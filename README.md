> [!IMPORTANT]

## Group Project Proposal
1. Write a scenario or case study that aligns with the our SDG (Quality Education).
2. Define suitable classes, attributes and methods.
3. Prepare an input file with a minimum of 20 records.
4. Propose and discuss at least FIVE (5) processes that logically apply to the data (insertion, removal, searching, updating, and traversing) using different data structures.
5. Explain the suitability of the two appropriate data structures for organizing the data:
> - The primary data structure used should be LinkedList.
>
> - The secondary data structure should be Queue or Stack
